## Despre CAEN Rev. 3

Clasificarea activităţilor din economia naţională (CAEN) este nomenclatorul care ierarhizează activitățile din economia națională a României. CAEN Rev. 3 reprezintă cea mai recentă actualizare a acestei clasificări, aliniată cu standardele Uniunii Europene.

Acest nomenclator este utilizat pentru:

- Înregistrarea activităților economice la Registrul Comerțului
- Clasificarea entităților economice în scopuri statistice
- Raportări fiscale și economice
- Diverse analize economice și sectoriale

## Format

Nomenclatorul CAEN Rev. 3 este disponibil în două formate:

- **CSV** - format tabelar simplu, care poate fi utilizat cu Excel sau alte programe de calcul tabelar
- **SQL** - script pentru importul direct în baze de date

Ambele fișiere conțin codurile CAEN complete, împreună cu descrierile activităților corespunzătoare.
